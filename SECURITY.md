# Security Policy

## Reporting a Vulnerability

Do not disclose security issues in public GitHub issues, discussions, or pull requests.

Report vulnerabilities privately to `security@bonzai.sh`. Include the affected version or commit, reproduction steps, impact, and any suggested mitigation. Remove wallet secrets, user data, connector credentials, and unrelated personal information from the report.

Please allow the maintainers time to reproduce and address the issue before public disclosure. BonzAI does not currently operate a paid bug bounty program.

## Scope

Security reports are especially important for:

- wallet, signing, staking, collectible, token, and smart-contract behavior
- connector credentials and authorization boundaries
- local company records, companion memory, and generated artifacts
- peer discovery, inference routing, and network isolation
- model downloads, archive extraction, and local code execution
- Electron IPC, preload APIs, and file access

Only test systems and assets you own or are explicitly authorized to assess.
